# MalariaGEN full human genotypes -- MANAGED access

Resource: https://www.malariagen.net/resource/25/
Package landing: https://www.malariagen.net/data_package/host-parasite-interaction/

Full human genotypes require an application. The parasite genome, the
joint host-parasite genotype dataset, and association summary statistics
are OPEN (downloaded via --download-open). Apply for full human genotypes
only if scientifically justified (host pharmacogenetics / G6PD / Hb variants).
